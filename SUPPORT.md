# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
bugs. Community support has no response-time SLA.

During beta, maintainers focus on the latest release and previous minor release,
macOS and Linux, Python 3.11-3.14, Node.js 20/22, and current Codex Desktop/CLI.
Windows, IDE integrations, and other Agent Skills clients are best effort.

Include `python3 --version`, `node --version`, the skill version or Git commit,
workflow profile, drawing mode, and redacted command output. Never include API
keys or private reference art.
