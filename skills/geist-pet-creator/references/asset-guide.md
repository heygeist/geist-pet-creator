# Bundled reference asset

## `assets/geist-house-style.jpg`

Use this image only as the house-form reference for Geist-compatible Pet
creation. It contains original Geist Pet examples showing the shared visual
grammar:

- rounded, legless floating body;
- thick Sky outline around a Cream body area;
- dot eyes, tiny mouth, and one centered Mango heart;
- flat color, compact attached props, and readable silhouettes.

When a Pet derives from a character, mascot, or object, attach this reference as
the style lock and attach the user-authorized source separately as the identity
lock. Do not treat the source's rendering style as a quality target.
